# Brainy

Brainy is a friendly thinking partner for messy notes, a public version of the Brainy chat in Brain Dump. Paste in a brain dump, meeting notes or a tangle of ideas, and it groups them under short headings, pulls out next steps and open questions, points out what connects, and helps you think a choice through one question at a time. Ask for a mind map and it draws one as a Mermaid diagram. It sees only what you paste into the chat, and saves nothing outside it.

## What it uses

Orca's free model, `orca/openrouter/cohere/north-mini-code:free`, so it needs no credit on any plan. The free model is shared, so at times it is busy, and it has a daily limit; see [pricing](https://orcapods.ai/pricing). No tools and no sandbox, so no machine time.

## Add it

Click **Copy** on the kit's page. You need an Orca account; signing up is free.

## Use it

```bash
orca chat brainy "Help me sort this: dentist sometime this month, Mum's birthday on Saturday and no gift yet, finish the slides for Thursday's team meeting, gym again?, read the book Jo lent me, fix the leaking tap, maybe start a newsletter about plants"
```

Or start a chat with brainy at [app.orcapods.ai](https://app.orcapods.ai) and paste your notes.
